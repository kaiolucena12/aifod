# AiFod Luxury — Mobile

Versão refinada especialmente para celular.

## Melhorias
- Header compacto e confortável no toque
- Stories horizontais com scroll suave
- Viewer de stories em tela cheia
- Tipografia responsiva no hero
- CTA em largura total
- Cards X / Comfort / Black empilhados e espaçados
- Modal de cadastro em formato bottom sheet
- Suporte a safe-area de iPhone
- Ajustes específicos para 820px, 520px e 390px
- Footer reorganizado para telas pequenas

## Rodar

```bash
npm install
npm run dev
```
